Sprint burndown

Remaining issues against an ideal line. Dates and daily snapshots use UTC.

Choose sprint dates, enter the selected issue numbers, then draw the chart.

The ideal line starts at the initial issue count and reaches zero at the end, decreasing on Monday–Friday only (public holidays are not excluded). Actual values use the latest snapshot each UTC day. Missing snapshots, missing selected issues or unknown statuses leave gaps.
